# Plans

Dated task plans for repository work. Open a plan here at the start of a
multi-step task and drive the task from it, keeping it current as work proceeds
(see [repo-records: Plans](../../references/repo-records.md#plans)).

Naming: `YYYY-MM-DD-slug.md`, or `YYYY-MM-DD-slug/` with `index.md` when a plan
grows phases, progress logs, or decision records. If a Paperclip issue owns the
plan, update that issue's `plan` document via the `paperclip` skill instead.

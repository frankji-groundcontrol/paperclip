# Practices

Reusable implementation practices: setups, module patterns, command sequences,
and operational methods that are worth repeating (see
[repo-records: Practices](../../references/repo-records.md#practices)).

A practice differs from a [learning](../learning/README.md) record: learning
captures *what was discovered*; a practice captures *a repeatable way to do
something*.

Naming: `YYYY-MM-DD-title.md`, or `YYYY-MM-DD-title/` with `index.md` when
examples, scripts, or variants will grow.

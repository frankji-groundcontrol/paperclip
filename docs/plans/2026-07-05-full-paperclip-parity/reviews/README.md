# Reviews

Review artifacts go here.

Required before implementation:

- `plan-eng-review.md` — engineering review of architecture, sequencing, edge cases, and verification.
- `codex-plan-review.md` — independent Codex review.
- `revision-log.md` — changes made after reviews.

Required after each implementation phase:

- `phase-N-codex-review.md`
- `phase-N-verification.md`
